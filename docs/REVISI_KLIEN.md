# Sumber Revisi Klien — Kue Pandan Asli

Dokumen ini adalah **salinan verbatim** catatan revisi dari Pak Dian & tim. Jangan diedit.
Rujuk file ini setiap kali butuh teks revisi; jangan mengandalkan ingatan/konteks.

## A. Temuan perilaku saat ini ("umum")

| Kode | Catatan asli | Tafsir awal |
|---|---|---|
| R-01 | "Kok jadi gabung Surabaya dan Malang(?) pada menu order selection pada menu pesanan" | Di langkah pilih pesanan, produk/harga Surabaya & Malang tercampur dalam satu daftar. |
| R-02 | "Pada Manajemen Produk juga kok foto jadi tidak dapat ditampilkan" | Bug foto tidak tampil di halaman admin Manajemen Produk. |
| R-03 | "Aku & Pak Dian sama sama pusing mas alur Pesanan nya (aku juga bingung pas tadi ditanyai)" | Alur pesanan membingungkan; perlu pemetaan & penyederhanaan. |
| R-04 | "Awalan semua produk ⭐List produk" | Menu awal/daftar produk diawali ⭐ "List produk". **Ambigu.** |
| R-05 | "Wa yang sudah masuk didata chat Bot tetap diberi pilihan Kota" | Nomor WA yang sudah tercatat masih ditanya kota lagi; kota seharusnya diingat. |
| R-06 | "Pada menu pilihan "harga" dan "produk" masih menggunakan pricelist harga lama" | Menu harga & produk masih membaca pricelist lama. |
| R-07 | "Pada saat memilih "pesan"" | **Terpotong.** Laporkan perilaku saat memilih "pesan"; butuh klarifikasi. |
| R-08 | "Tidak ada pilihan "menu" sehingga tidak ada Pilihan Kategori Produk" | Perlu opsi "menu" yang membuka pilihan kategori produk. |
| R-09 | "Setiap katalog diberi "Katalog Produk Kue Pandan Asli Surabaya" nama kota nya (karena harga sby lebih mahal)" | Judul katalog wajib memuat nama kota. |

## B. Revisi eksplisit

| Kode | Catatan asli | Tafsir awal |
|---|---|---|
| R-10 | "Revisi : Tolong Ditambahkan di dalam menu "Masuk keranjang" di beri ketik "Mau pesan apa?" Agar tidak perlu scroll panjang keatas mencari hanya mencari menu "Mau pesan apa?"" | Setelah item masuk keranjang, tampilkan lagi prompt "Mau pesan apa?" di bagian bawah pesan. |
| R-11 | "Note : mungkin diberikan pilihan seperti memilih kota malang/sby jadi customer tidak perlu scroll keatas untuk liat menu" | Pilihan ganti kota (Malang/SBY) mudah dijangkau di bawah. Sifat: saran ("mungkin"). |
| R-12 | "Penggunakan tanda "-" pada bagian sub produk" | Sub produk memakai awalan "-". **Ambigu** (menambah/mengganti/memperbaiki?). |
| R-13 | "Revisi : kalau tumpeng, kue mix dan hampers keterangan hanya cukup isi" | Untuk tumpeng, kue mix, hampers: keterangan cukup menampilkan isi saja. **Ambigu.** |
| R-14 | "Revisi Produk : ada Produk Baru" | **Data produk baru tidak diberikan** → blocker data. |
| R-15 | "Harga Khusus Surabaya" | **Daftar harga tidak diberikan** → blocker data; cek dukungan harga per kota. |
| R-16 | "Hilangkan kata cabang jadi langsung, Kue Pandan Asli Malang/Surabaya" | Ganti semua teks "cabang" → "Kue Pandan Asli Malang/Surabaya". |
| R-17 | "Tetap berikan no admin malang & SBY untuk keperluan mengganti lokasi, memberi tahu pesanan" | Nomor admin kedua kota tetap tampil (ganti lokasi & konfirmasi pesanan). |
| R-18 | "Dari tito :pada format contoh berikan contoh format lengkap , jadi yang pesan tau mau nulis apa )(ex : Jl dandangan no 2, depan Balai Desa. No Penerima : 088170xxxxx)" | Contoh format input (alamat, no penerima, dll.) harus lengkap & konkret. |
